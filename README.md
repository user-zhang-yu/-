# 短信系统 使用教程

## 一、两个程序的区别

| 程序 |适合场景 |
|---|---|
| 短信群发系统.exe | 纯批量群发 + 接收监听，界面简洁 |
| 短信系统.exe（模板版）| 单人发送 + 批量发送 + 接收 + 联系人记忆 + 连接检测，功能最全 |

两个程序共用同一套手机网关（HTTP API），配置方式一样。

---

## 二、准备工作（必须先做）

### 1. 手机上安装短信网关 App
在手机上安装支持 HTTP API 的短信网关应用（如 SMS Gateway 类 App），开启服务后记下：
- 手机的 IP 地址（App 里会显示，如 10.241.110.111）
- 端口号（默认 8080）
- 账号 / 密码（App 里设置的 Basic Auth 账号）

### 2. 手机和电脑连同一个 WiFi
电脑必须能访问手机的 IP。如果手机换了网络，IP 会变，需要更新程序里的配置。（亲测可以手机开热点，然后连接电脑，效率会很高）

### 3. 给 App 授权
在手机设置里给网关 App 开启：
- 发送短信权限
- 读取短信 / 通知监听权限（用于接收回复）
- 后台运行权限（加电池白名单，防止被系统杀掉）

---

## 三、通用操作：连接网关

打开任意一个程序，顶部都有网关配置栏：

`
IP: 255.255.255.0  端口: 8080   账号: username   密码: ********   [测试连接]
`

1. 填入手机网关的 IP、端口、账号、密码。
2. 点「测试连接」按钮：
   - 变绿 ✓ 已连接 → 可以发送了
   - 变红 ✗ 连接失败 → 看状态栏提示原因
3. **模板版**：没测过连接时，发送按钮点了会提示"请先点测试连接"，发不出去。
4. 改了 IP/端口/账号/密码任意一项，连接状态自动失效，需要重新测。

## 四、旧版（短信群发系统.exe）使用

### 批量发送

1. 点「浏览」选择 Excel 名单文件（.xlsx / .xls）。
2. 选完后下方会显示表头，并自动预选电话列（含"电话/手机"的列）。
3. 确认「电话列」下拉框选的是正确的手机号列。
4. 在「消息模板」框里编辑短信内容，用 {列名} 占位，例如：
   `
   【****】恭喜{姓名}同学被正式录取，学号{学号}，期待你的到来！
   `
   发送时每行数据会自动替换 {姓名}、{学号} 为对应单元格的值。
5. 点「▶ 开始发送」。
6. 发送过程中可以点「■ 停止发送」中断。
7. 完成后在 Excel 同目录生成：
   - 发送成功_时间戳.csv
   - 发送失败_时间戳.csv（含失败原因）

### 接收监听

1. 点「▶ 开始监听回复」。
2. 程序每 5 秒轮询一次手机收件箱，新回复实时显示在右侧「回复收件箱」标签页。
3. 回复同时追加到程序目录下的 回复记录.csv。
4. 点「■ 停止监听」可随时停止（立即响应，不会卡住）。
5. 点「打开回复记录」可直接打开 CSV 文件。

## 五、模板版（短信系统.exe）使用

程序有 5 个标签页：

### 标签1：单人发送

- **手机号**：直接输入号码，输入时会自动从联系人记忆里补全候选（下拉显示）。
- **从联系人选**：点按钮跳到联系人标签页，双击某行自动回填手机号。
- **消息内容**：输入要发的短信。
- **立即发送**：发送单条短信。

### 标签2：Excel 批量发送

1. 点「浏览」选 Excel 文件。
2. 下方显示表头，「电话列」下拉框自动预选，可手动改。
3. 在「消息模板」里写短信，用 {列名} 占位。
4. 点「👁 预览第一条」看第一行数据渲染后的效果。
5. 点「▶ 开始批量发送」，进度条实时显示。
6. 可随时停止。

### 标签3：接收监听

1. 「回复保存目录」选一个文件夹（默认程序目录）。
2. 点「▶ 开始监听」。
3. 新回复实时显示，并追加到所选目录的 回复记录.csv。
4. 点「■ 停止监听」停止。

### 标签4：联系人记忆

- 程序自动记录所有发过/收过短信的人（手机号、姓名、发送数、接收数、最近联系时间），存在 contacts.db。
- 搜索框可按手机号/姓名过滤。
- 双击某行 → 自动回填到「单人发送」标签页。

### 标签5：连接检测

点「🔍 开始检测」，一键跑 5 项检查：

| 步骤 | 检查内容 | 常见失败原因 |
|---|---|---|
| 1 | 配置是否填全 | 漏填 IP/端口/账号/密码 |
| 2 | TCP 网络连通 | 不在同一 WiFi、App 没开、防火墙 |
| 3 | 账号认证 | 账号密码错误 |
| 4 | 发送接口 | App 版本旧、路径不对 |
| 5 | 接收接口 | 没开短信读取权限、被省电杀掉 |

每步失败时直接给出解决方案，最后给总结。

## 六、Excel 名单格式要求

- 第一行必须是表头（列名），程序按表头识别列。
- 手机号列可以叫任意名字（电话、手机、手机号、联系电话…），在「电话列」下拉里选对就行。
- 手机号可以带 +86 或不带，程序自动处理。
- 空行（电话列为空）会自动跳过。
- 模板里的 {列名} 必须和 Excel 表头完全一致（区分大小写）。

### 示例 Excel

| 姓名 | 学号 | 专业 | 电话 |
|---|---|---|---|
| 张三 | 2024001 | 计算机 | 13800138000 |
| 李四 | 2024002 | 电子 | 13900139000 |

模板：【通知】{姓名}同学，你的学号{学号}已确认，请查收。

## 七、常见问题

### Q: 测试连接提示"网络不通"
- 确认手机和电脑连同一个 WiFi
- 确认手机网关 App 正在运行、服务已开启
- 确认 App 显示的 IP 和程序里填的一致（手机换网后 IP 会变）
- 关掉电脑 VPN / 手机热点
- 检查电脑防火墙是否拦了端口

### Q: 提示"账号或密码错误"
- 核对 App 里设置的 Basic Auth 账号密码，区分大小写

### Q: 能发但收不到回复
- 确认 App 开启了「读取短信 / 通知监听」权限
- 确认 App 没被系统省电策略杀掉（加后台白名单）
- 用「连接检测」标签页看第 5 步是否通过

### Q: 界面看起来模糊
- 程序已开启 Per-Monitor DPI 感知，高分屏应该清晰。如果仍模糊，右键 exe → 属性 → 兼容性 → 更改高 DPI 设置 → 勾选"替代高 DPI 缩放行为"，缩放执行选"应用程序"。

### Q: 发送速度慢
- 每条短信之间默认间隔 3 秒（旧版）/ 1.5 秒（模板版），这是为了避免运营商限流。不要改太短。

### Q: 换电脑运行
- 直接复制 exe 即可，不需要装 Python 或任何依赖（PyInstaller 已打包）。
- 网关配置、联系人数据存在 exe 同目录，换电脑时一起复制。

## 八、文件说明

### 旧版目录 F:\项目集合\短信系统\
- 短信群发系统.exe — 主程序（最新版）

- 短信系统_GUI_v2.py — 源码
- 回复记录.csv — 接收的短信（运行后生成）

### 模板版目录 F:\项目集合\短信系统\适配所有的\
- 短信系统.exe — 主程序
- 短信系统.py — 源码
- 
equirements.txt — Python 依赖（跑源码时用）
- gateway_config.json — 网关配置（运行后自动生成）
- contacts.db — 联系人数据库（运行后自动生成）
- 回复记录.csv — 接收的短信（在你选的保存目录）
